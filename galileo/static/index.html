Point a phone at an experiment. Get the physics, with error bars.

Measuring motion usually takes a stopwatch and a guess, or a high-speed camera. Isochron AI is a measuring instrument in a phone video: Muse Spark finds the moving object, SAM 3.1 follows it on every frame, tested code fits the physics with an error bar, and an agent checks its own predictions blind.

From a video to a measurement in four steps.

The models look and track; every number is computed by code that is tested against videos with a known answer. The AI never does the arithmetic.

1

Film it

Any phone, held still. Exact frame times are read from the file (phones record a variable frame rate), and camera shake is measured and removed.

Code
2

Look at it

Muse Spark sees ten frames, names the experiment, picks the object and the first frame where it moves freely, and points out problems with the setup.

Muse Spark
3

Track it

SAM 3.1 gets one point on that frame and returns a mask of the object on every frame after it. Its centre is the measured position, to a fraction of a pixel.

SAM 3.1
4

Measure, predict, check

Competing models are fitted and compared; uncertainties are propagated. An agent registers a prediction for the next experiment and verifies it blind.

What it measures today.

A period, a damping rate, a bounce, a vibration: a number with an honest error bar. The video-to-motion part is the same for any moving object; each kind of experiment adds its own physics.

Pendulum

A weight on a string.

  • Period and small-angle period
  • g, from the period and the length
  • Which damping law the data supports
Real result: g = 9.821 ± 0.126 m/s² from four lengths, 0.24 % from the local value.

Bouncing ball

Drop a ball on a hard floor.

  • Bounciness (coefficient of restitution)
  • Impact times to about a millisecond on 30 fps
  • How far it fell, measured two independent ways
Real result: e = 0.8638 ± 0.0004 for a golf ball on laminate, 8 impacts.

Anything that oscillates

A spring, a ruler on a table edge, a swing, a branch.

  • Period and frequency
  • Damping rate and quality factor Q
  • No length or scale needed
Same fits as the pendulum, without the pendulum-only steps.

Run it on your own video

The same site, with the camera and live progress, on your computer. A run costs about $0.10–0.25 of your own API credits.

git clone https://github.com/Giochvanno/hackathon-meta-galileo
cd hackathon-meta-galileo
pip install -e ".[web]"
cp .env.example .env                    # then put your key in .env
uvicorn galileo.web:app --port 7860    # open http://localhost:7860

Or straight from the command line: python -m galileo.cli pendulum video.mp4 --auto --length 0.489. No key? Re-measure our real runs for free: see Try it in 2 minutes.

Run it yourself.

Everything on this page is the open-source command line, with a Meta Model API key.

Measure a video

Muse Spark sets it up, SAM 3.1 tracks, the physics is fitted.

pip install -e ".[web]"
python -m galileo.cli look     video.mp4
python -m galileo.cli pendulum video.mp4 --auto --length 0.489
python -m galileo.cli bounce   video.mp4 --auto --drop-height 0.30
python -m galileo.cli oscillate video.mp4 --auto

Let the agent run the lab

Add experiments to the notebook; the agent picks the model, estimates g, predicts the next experiment and checks it when you film it.

python -m galileo.cli lab add runs/video/track.csv --length 0.489
python -m galileo.cli agent
python -m galileo.cli lab show
uvicorn galileo.web:app --port 7860   # this site
